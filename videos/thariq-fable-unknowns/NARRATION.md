# 旁白脚本 · 3 分钟视频

> **用途**：自己配音用
> **总时长**：180 秒（3:00）
> **总字数**：~480 字
> **节奏**：平均 2.7 字/秒，editorial 调性
> **录音建议**：在安静环境用 USB 麦；全程一次过；中间换气点已标注

---

## 录制须知

- **`/`** 符号 = 0.3 秒小停顿（换气用）
- **`//`** 符号 = 0.8 秒停顿（句子间留白）
- **`【】`** = 语气/动作提示（不要念出来）
- **`*重点*`** = 该处需要略加重语气
- **`…` 省略号** = 自然气口，不要拖太长

**英文词发音速查**（录音前先念 2 遍熟悉）：
- Thariq → 塔里克（Tha-rik）
- Claude → Kluud（按英文发音，不念"克劳德"）
- Fable → Fey-bull
- prompt → prompt（保留英文）
- skill / context → 保留英文
- unknowns → 保留英文，读"安-诺恩斯"
- Buy-in / merge / Remotion / ffmpeg / Whisper → 全部保留英文
- `斜杠` → 念"斜杠"（不要念英文 slash）

## 录音小贴士

1. **正式录前先念 2 遍**：让节奏进入身体
2. **每个 Beat 单独录一遍**：3 分钟一次过难度大，分段录更稳
3. **关键停顿处**：真的停 0.5-1 秒，编辑时可压缩，但留原始气口录音更自然
4. **英文词处**：如果卡壳，可以念"斜杠 unknown"（用同义词替代），但尽量按速查表
5. **最终混合**：录音 + 视频 mp4 + BGM 在剪辑软件（如剪映、Final Cut）合成
6. **响度建议**：旁白 -3dB 至 -6dB，背景乐 -18dB 至 -24dB，留足人声空间
