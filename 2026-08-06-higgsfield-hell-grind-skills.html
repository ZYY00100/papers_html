01
CORE FORMULA

The MCSLA Formula

MCSLA 五层公式——所有 prompt 的骨架
CORE PRINCIPLE 每条 Higgsfield prompt 都由五层组成：M（模型）+ C（镜头）+ S（主体）+ L（视觉风格）+ A（动作）。填好五层，模型就有了它需要的一切。Hell Grind 108K+ 次生成，每一条 prompt 都跑过这个公式。
01 higgsfield-prompt MCSLA 提示工程核心 
- MCSLA = Model, Camera, Subject, Look, Action — the five layers of every prompt
- I2V: describe ONLY what moves or changes, never what's already in the image
- Keep prompts under 200 words — **short-form MCSLA regime only**; block-scaffold production prompts replace the cap with structural lint (HARD RULE 8 carve-out); Cinema Studio has a hard 512-character cap
- 1 primary action per clip, 1–2 secondary max; Fast Motion Trick: render in Slow Mo, speed up in post
- Never leave a generic emotion ("sad"/"angry") in a prompt — decompose into muscle movements, breath, eyes, skin
- Soul ID / recurring characters: split every prompt into Identity Block + Motion Block — never mix them
- Conflict order when sub-skills disagree: explicit user direction > scene archetype > emotion-sync
- Aspect ratio is a per-model enum set in the UI/header, never in the prompt body — verify via `../../specs/model-specs.yaml`
- Never combine Dolly In + Dolly Out in one shot; @ Elements for static scenes, plain text for action
- Iterate by changing exactly ONE variable per regeneration
- 6-Pass Diagnostic order: Subject → Action → Camera → Style → Audio → Output; most failures land on Pass 1–2
- Seedance short-form: 30–100 words win; Subject + Action in the first 20–30 words. Block-scaffold production briefs run 218–2,059-word medians by register — see `../higgsfield-seedance/SKILL.md` § Official Prompt Architecture
- Genre length targets: Product 30–50w, Lifestyle 40–60w, Drama 60–100w, Music Video 50–80w, Anime 50–90w
- Kill slop words (beautiful, stunning, epic, amazing) — replace with concrete visuals/physics
- Seedance/CS 3.0 has NO negative-prompt syntax — phrase as positive constraints
- Dialogue cap: ~25–30 spoken words fit in 15 seconds — keep the power-shift line, convert the rest to behavior
- Engine limits: ≤3 characters tracked across cuts; exit-frame = gone; off-screen = nonexistent; avoid reflections
- Every cut must change BOTH shot size AND camera character
- Age-blind rule: never boy/girl/child/kid/young/teen/little — describe by role, clothing, action
- Scenes start already in progress unless the user says "starts with…" or "ends with…"
MCSLA = Model（模型）、Camera（镜头）、Subject（主体）、Look（视觉风格）、Action（动作）—— 每条 prompt 的五层骨架，缺一不可
- I2V（图生视频）：只描述画面里"动了或变了"的部分，不要重新描述图里已有的内容
- 单条 prompt 控制在 200 词以内；Cinema Studio 硬上限 512 字符
- 一个镜头一个主动作，最多 1–2 个次动作；想让动作变快 → 用 Slow Mo 拍，后期加速
- 别留 "sad" / "angry" 这类笼统情绪词——拆成肌肉、呼吸、眼神、皮肤微动
- Soul ID / 复用角色：每条 prompt 拆成 Identity Block（静态）+ Motion Block（动作）—— 永远分开写
- 子 skill 之间矛盾时优先级：用户明确指示 > 场景原型 > 情绪同步
- 画幅比例是每个模型在 UI/header 里设的 enum，不要写在 prompt 里
- 一个镜头里别同时写 Dolly In + Dolly Out；静态用 @ Elements，动作直接写正文
- 每次重生成只改一个变量
- 6-Pass 诊断顺序：Subject → Action → Camera → Style → Audio → Output；多数失败发生在第 1–2 步
- Seedance 短 prompt 50–80 词最佳，Subject + Action 必须在前 20–30 词
- Genre 长度目标：Product 30–50w · Lifestyle 40–60w · Drama 60–100w · MV 50–80w · Anime 50–90w
- 删掉 slop 词（beautiful / stunning / epic / amazing）—— 用具体画面或物理替换
- Seedance / CS 3.0 没有 negative prompt 语法 —— 用正向约束表达
- 对白上限：15 秒里塞得下 25–30 个英文单词 —— 保留 power-shift 一句，其余转行为动作
- 引擎硬限制：跨镜头最多追踪 3 个角色；出框 = 消失；屏外 = 不存在；避免反射
- 每次 cut 必须同时改变景别和镜头语态
- Age-blind：禁用 boy / girl / child / kid / young / teen / little —— 用角色、服装、动作描述
- 默认从镜头中段开始，除非用户说 "starts with…" 或 "ends with…"
02
FRAMING & ANGLE

Framing, Angle & Camera

镜头与画面——景别 / 角度 / 运动关键词 / 镜头语态
CORE PRINCIPLE 静态图靠景别 + 角度 + 运动暗示三层叠加造出"画面感"；视频靠 named preset（dolly / crane / orbit / zoom / follow 等）+ 镜头是主角情绪替身的原则造出"镜头语态"。所有预设名必须按官方 exact name 引用。
02 higgsfield-image-shots 电影级静态图构图 
- Scope: still-image composition only; `[img 1]` is the Soul ID / uploaded reference token — replace with a character description or @ Element when no reference is used
- Base pattern: [Shot keyword] of [img 1 or character description] + [pose/action] + [environment detail] + [lighting/atmosphere]
- 10 framing sizes, EWS → Macro: EWS tiny-in-landscape, Wide full body, Full head-to-toe, MLS knees up, Cowboy mid-thigh up, Medium waist up, MCU chest up, CU face, ECU single detail, Macro texture
- Framing keywords: "EWS, Vast, Landscape" / "Wide Shot, Full Body" / "Cowboy Shot" / "MCU" / "Close-Up" / "ECU" / "Macro"
- 10 angles: Eye-Level, Low Angle, High Angle, Overhead, Worm's Eye, Dutch/Canted, OTS, POV, Selfie, Ground Level
- Angle = emotional read: Low = power, High = vulnerability, Dutch = unease/chaos, Worm's Eye = extreme power/surreal
- Multi-word angle keywords: "POV, First Person Perspective" / "Selfie Angle, Arm's Length" / "Ground Level, Surface View"
- OTS = looking past one person's shoulder at another — essential for dialogue
- Movement keywords create the FEELING of motion in a single frame — motion blur, implied movement, frozen mid-movement
- Static/Basic movements: Static, Pan, Tilt, Zoom In / Zoom Out, Pedestal Up/Down
- Advanced Physical movements: Dolly In, Dolly Out, Truck Left/Right, Orbit, Crane
- Cinematic & AI movements: Dolly Zoom (Vertigo), Crash Zoom, FPV, Bullet Time, Handheld Follow, Camera Roll, Rack Focus, Pull Back Reveal, Fly-Through
- Strongest prompts layer all three: [Distance/Size] + [Angle] + [Movement hint] + Subject + Environment + Lighting
- Full formula closes with [Lighting — time of day, source, quality] then [Style — cinematic, film stock, color grade]
- 只管单帧画面构图；`[img 1]` 是 Soul ID 或上传参考图 —— 无参考图时换成角色描述或 @ Element
- 基础公式：[景别关键词] of [img 1 或角色描述] + [姿势/动作] + [环境细节] + [光影/氛围]
- 10 个景别：EWS / Wide / Full / MLS / Cowboy / Medium / MCU / CU / ECU / Macro
- 景别关键词示例："EWS, Vast, Landscape" / "Wide Shot, Full Body" / "Cowboy Shot" / "MCU" / "Close-Up" / "ECU" / "Macro"
- 10 个角度：Eye-Level / Low / High / Overhead / Worm's Eye / Dutch / OTS / POV / Selfie / Ground Level
- 角度 = 情绪读法：Low = 力量，High = 脆弱，Dutch = 不安/混乱，Worm's Eye = 极端力量/超现实
- 多词角度："POV, First Person Perspective" / "Selfie Angle, Arm's Length" / "Ground Level, Surface View"
- OTS = 越过一个人的肩膀看向另一个 —— 对话场景必备
- 运动关键词在静态图里造出"运动感" —— motion blur / implied movement / frozen mid-movement
- Static / Basic：Static, Pan, Tilt, Zoom In/Out, Pedestal Up/Down
- Advanced Physical：Dolly In/Out, Truck Left/Right, Orbit, Crane
- Cinematic & AI：Dolly Zoom（Vertigo 效果）/ Crash Zoom / FPV / Bullet Time / Handheld Follow / Camera Roll / Rack Focus / Pull Back Reveal / Fly-Through
- 最强 prompt 三层叠加：[景别] + [角度] + [运动暗示] + 主体 + 环境 + 光影
- 公式末尾用 [光影 —— 时间/光源/质感] 再接 [风格 —— cinematic/film stock/调色]
03 higgsfield-camera 镜头控制全景 
- Named preset tables by family: dolly / crane / orbit / zoom / follow / specialty / time-based / through-object / vehicle, plus angles and shot sizes — always cite the **exact preset name**
- Layer max two *compatible* moves; sequenced combos get explicit timing; static-pan beats glide for most coverage
- **The camera is the emotional double of the focal character** — 7 emotional registers map to camera prescriptions; arcs change the camera in named phases
- [OFFICIAL] Lens + aperture chosen by shot *purpose* (85/100mm F1.4 tight emotional CU … 45mm macro F2.8), with standing focus-lock and distortion-forbid clauses
- [OFFICIAL] Shot duration by type: flash establish 0.3–0.5s · dialogue line 3–7s · wordless reaction 5–10s · full-arc emotional CU 8–15s
- Micro-moves need exact distances — state total travel + time ("10–15 cm over 7 seconds"); never write `zoom` for a physical move
- Cinema Studio 3.0: One-Move Rule, genre presets, reliable phrasing library, camera transfer via `@Video`
- What a `@Video` reference reads reliably (world, materials, physics, camera character) vs cannot do (frame-accurate continuation, identity)
- 命名预设按家族分类：dolly / crane / orbit / zoom / follow / specialty / time-based / through-object / vehicle —— 必须用准确的预设名
- 单镜头最多叠两个 *兼容* 的运动；多段串联要写明时间节奏；多数情况下 static-pan 比 glide 镜头更稳
- 镜头是主角情绪的替身 —— 7 种情绪状态对应镜头处方；角色情绪弧变化时镜头要分阶段换
- 镜头 + 光圈按镜头 *目的* 选：85/100mm F1.4 拍特写情绪，45mm macro F2.8 拍细节；常驻 focus-lock 和 distortion-forbid 条款
- 单镜头时长按类型：flash establish 0.3–0.5s · dialogue line 3–7s · wordless reaction 5–10s · full-arc 情绪 CU 8–15s
- 微距运动必须给精确距离 —— 写明总行程 + 时间（如"10–15 cm over 7 seconds"）；别用 zoom 描述物理运动
- Cinema Studio 3.0：One-Move Rule、genre presets、可靠措辞库、`@Video` 传递镜头
- `@Video` 参考能稳定读取：场景 / 材质 / 物理 / 镜头语态；不能做到：逐帧续拍 / 角色一致性

STYLE & MOTION

Visual Style & Motion Presets

视觉风格 + 命名动作预设——Style / Cinematic / VHS / Anime + VFX 预设库

04 higgsfield-style 视觉风格 + 色调 
Five named platform styles. Always reference by exact name.

[Style 1] Cinematic
Look: Polished, high-contrast, vivid colors, balanced exposure — modern blockbuster
Best for: Drama, action, narrative films, commercials, any professional content
Color tendency: Rich, saturated, clean
Prompt phrase: "Style: Cinematic"
Pair with: Kling 2.6/3.0, Sora 2, Dolly In, Arc, Crane Up

[Style 2] VHS
Look: Retro videotape grain, color bleed, slight scanlines, analog imperfection
Best for: 80s/90s nostalgia, horror, thriller, retro music videos, flashbacks
Color tendency: Slightly washed out, warm yellows/reds, low contrast
Prompt phrase: "Style: VHS"
Pair with: Handheld camera, Wan 2.5, any horror preset

[Style 3] Anime
Look: Hand-drawn anime aesthetic, bold outlines, vibrant flat colors
Best for: Anime-style content, stylized narratives, music videos
Color tendency: Saturated, varied per scene
Prompt phrase: "Style: Anime"

[Style 4] Cinematic Anime
Look: Anime aesthetic + cinematic grading, cel-shaded characters in filmic lighting
Best for: Anime films, hybrid realism
Prompt phrase: "Style: Cinematic Anime"

[Style 5] Vintage Film
Look: 70s/80s film stock, faded colors, slight grain, warm highlights
Best for: Period pieces, nostalgic content, music videos
Color tendency: Washed, warm yellows, faded reds
Prompt phrase: "Style: Vintage Film"

Example prompt:
A detective walks through a night market.
Style: Cinematic. Cold blue shadows, warm amber market stall light.
Shallow depth of field. 16:9.

04
CINEMA STUDIO ADVANCED

Cinema Studio · Seedance · Soul ID

Cinema Studio 进阶——多镜头工作流 / Seedance 2.0 / Soul ID 角色一致性
CORE PRINCIPLE Cinema Studio 三版本共存（2.5 / 3.0 / 3.5）；Seedance 2.0 的过滤器是 LLM 在读全场景意图、不是关键词黑名单；Soul ID 把每条 prompt 拆成 Identity Block + Motion Block 让角色跨镜头不漂。Hell Grind 90 分钟 + 253 个镜头就是这三套机制撑起的。
06 higgsfield-cinema Cinema Studio 全功能 
- Three Cinema Studio versions coexist (2.5 / 3.0 / 3.5) — user-selected, no auto-routing; always detect the version first
- Hard 512-character prompt cap; 2.5 @ Element chips eat ~80–100 hidden chars each
- Elements System: define @Characters/@Locations/@Props once, call everywhere
- 3.5 main UI = three pills (Genre / Style / Camera), each Auto by default — override only with a creative reason
- 7 confirmed 3.5 genres: General · Action · Horror · Comedy · Noir · Drama · Epic — never invent genre names
- Style presets: 8 Color Palettes · 6 Lighting · 9 Camera Moveset Styles, or free-form Manual Style
- Camera axes: 3 bodies · 5 lenses · focal 8/14/35/50/75mm · aperture f/1.4–f/4–f/11; two camera vocabularies coexist — vocabulary follows the selected model
- Output enums: 7 aspect ratios incl. 21:9 · 480p/720p/1080p · duration 4–15s · Sound On/Off
- Lead every delivered shot with the one-line settings strip (UI presets ≠ prompt text; never restate strip values in the body)
- The UI shot counter caps internal cuts — "strictly N shots" must keep N within it (observed cap 4; API exposes no max — UI behavior, verify live)
- Manual Style = saved ≤2,000-char block of project LAWS (grade, lighting law, texture, performance register); it replaces the preset axes
- 480p drafts validate the prompt, NOT the take — no seed param; transfer a look via Hero Frame + start/end-frame pinning
- Resolution matrix has two axes: shot physics × delivery context; 4K-finish pipelines master at model max res in std mode
- Seedance fast mode cannot output 1080p — drafting in fast then "switching up" silently changes mode AND res
- Cinema Studio 三版本（2.5 / 3.0 / 3.5）共存 —— 用户自选，不自动路由；先识别版本
- 硬性 512 字符 prompt 上限；2.5 @ Element chip 每个占 ~80–100 隐藏字符
- Elements 系统：先定义 @Characters/@Locations/@Props，到处复用
- 3.5 主界面 = 三 pills（Genre / Style / Camera），默认都是 Auto —— 有创意理由才覆盖
- 3.5 七种 genre：General / Action / Horror / Comedy / Noir / Drama / Epic —— 不要自创 genre 名
- 风格预设：8 调色板 · 6 灯光 · 9 镜头语态风格，或自由 Manual Style
- 镜头四轴：3 机身 · 5 镜头 · 焦距 8/14/35/50/75mm · 光圈 f/1.4–f/4–f/11；两套镜头词汇共存，词汇跟所选模型走
- 输出 enum：7 画幅（含 21:9）· 480p/720p/1080p · 时长 4–15s · Sound 开/关
- 每个交付的镜头开头写 settings strip 一行（UI 预设 ≠ prompt 文本，body 里不要重复 strip 值）
- UI shot counter 限制内部 cut 数量 —— "strictly N shots" 的 N 必须在 cap 内（实测 cap 4，API 没暴露 max）
- Manual Style = 项目 LAWS 的 ≤2000 字符块（调色、灯光法、质感、表演寄存器）；它替换 preset 四轴
- 480p 草稿验证的是 prompt 不是成片 —— 无 seed 参数；靠 Hero Frame + 首尾帧 pinning 传递视觉风格
- 分辨率矩阵两轴：镜头物理 × 交付上下文；4K 终混在 std 模式下 master 到模型最大分辨率
- Seedance fast 模式不能出 1080p —— 先用 fast 草稿再"升档"会偷偷改模式 + 分辨率
07 higgsfield-seedance Seedance 2.0 提示导演 
- The filter is an LLM reading full-scene intent, not a keyword blacklist — describe a SCENE, not a subject; fix the voice first
- Instant fail (<10s) = filter rejection; delayed fail (>30s) = infra/complexity — never regenerate an instant fail unchanged
- Six slots, in order: Camera + Subject + Action + Setting + Style + Lighting; missing 3+ slots is where flags come from
- Empirical prompt-craft laws: 50–80-word attention sweet spot (front-load the load-bearing element), name a director/lens not "cinematic", "fast" degrades motion, no negative prompts in the body
- Five prompt modes: Reference-Based / Continuation / Expand Shot / Edit Shot / Transformation — pick the mode before writing
- [OFFICIAL] block scaffold for production prompts: SCENE CONTEXT → … → POSITIVE LOCKS, distributed style on standalone briefs (connected shotlists glue the compiled Style Prefix verbatim instead), FOV in degrees only, CAMERA block 3rd, cut ladder oner / CUT n / timed / freestyle
- [FIELD] 13-project corpus calibration: word length scales with register (218w → 2,059w medians — the 50–80w sweet spot is single-shot-only), video briefs hand-authored (`enhance_prompt` off), Style Prefix = per-project constant compiled into home blocks
- [FIELD] Three "helpful-instinct" drift sources, each with a standing lock: environment invention (#1, above character drift), character-height equalization, scale drift on wides
- Build-safe construction for crowds/destruction/creatures: evacuated cities, contained fights ("stays at the sea surface"), the safe benchmark scene
- Extend an existing clip: attach it as a video reference + open with "The scene continues." — match source resolution AND duration; chain cap ~2 (hard 3), then re-anchor from ORIGINAL references
- Tutorial-demonstrated patterns (reference-role vocabulary incl. VARIETY reference, SCREEN REALISM + duration-match composites, 60:30:10 grade, red-arrow prop annotation): `PRODUCTION-PATTERNS.md` in this directory
- Hard engine rules (age-blind, exit-frame = cut, off-screen = nonexistent, no reflections, ≤3 tracked characters, double-contrast cuts) + high-risk shot table: `ENGINE-RULES.md` in this directory
- Reference roles: Character / Last-Frame / Environment / Prop — role determines what the prompt may re-describe
- Working modes: Exploration / Continuation / Bridging / Repair (distinct from prompt modes)
- Layer 1 briefing vs Layer 2 production prompt — never paste Layer 1 into the prompt box
- Native **4K** is available in `mode=std` only; `mode=fast` (Seedance 2.0 Fast) caps at 480p/720p — in Cinema Studio the model is still capped at 1080p
- Always preflight: `python3 scripts/seedance_lint.py --preflight --model seedance_2_0 "<prompt>"` — enums come from `../../specs/model-specs.json` (fast+1080p/4K and Kling 21:9 are auto-caught)
- 480p drafts validate the prompt, NOT the take — no seed param; pin Hero Frame + start/end frames to carry a look
- ZH prompts: hard 1,800-char cap; ZH antislop list enforced by the linter
- Flagged prompt → rewrite playbook per linter rule, then voice pass
- Repeated flags → full loop-breaker procedure + LOG THE OUTCOME (`--confirmed` / `add-quality`)
- 过滤器是 LLM 在读全场景意图，不是关键词黑名单 —— 描述场景 SCENE 而不是主体 subject；先调通语气
- 立刻失败（<10s）= 过滤器拒绝；延迟失败（>30s）= 基础设施或复杂度问题 —— 立刻失败的原样重做绝对不行
- 六 slot 顺序：Camera + Subject + Action + Setting + Style + Lighting；缺 3 个以上 slot 就是被 flag 的源头
- Prompt 经验法则：50–80 词注意力甜区（核心元素前置），说导演/镜头名而不是说 "cinematic"，"fast" 拉低动作质量，body 里不要写 negative prompt
- 五种 prompt 模式：Reference-Based / Continuation / Expand Shot / Edit Shot / Transformation —— 写之前先选模式
- [官方] 制作 prompt 的 block scaffold：SCENE CONTEXT → ... → POSITIVE LOCKS，distributed style 用在 standalone brief；连起来的 shotlist 用编译好的 Style Prefix 串联；FOV 只用度数；CAMERA block 第 3 位；cut 阶梯 oner / CUT n / timed / freestyle
- [实战] 13 个项目语料校准：词数随寄存器伸缩（218w → 2059w 中位数 —— 50–80w 甜区只对单 shot 有效）；视频 brief 手写（`enhance_prompt` 关闭）；Style Prefix = 每项目常量编译进 home block
- [实战] 三个"好心办坏事"的漂移源，每条对应常驻锁：环境发明（最严重，超过角色漂移）、角色身高拉平、宽幅画面的尺度漂移
- 人群 / 破坏 / 怪物的安全写法：清空的城市、限定空间的打斗（"stays at the sea surface"）、安全基准场景
- 续拍：作为视频参考附上 + 以 "The scene continues." 开头 —— 匹配源分辨率和时长；串联上限 ~2（hard 3），然后从 ORIGINAL 参考重新锚定
- 教程演示模式（参考角色词汇含 VARIETY reference、SCREEN REALISM + 时长匹配合成、60:30:10 调色、红箭头道具标注）：本目录下 `PRODUCTION-PATTERNS.md`
- 引擎硬规则（age-blind、exit-frame = cut、off-screen = nonexistent、no reflections、≤3 追踪角色、double-contrast cut）+ 高风险镜头表：本目录下 `ENGINE-RULES.md`
- 参考角色：Character / Last-Frame / Environment / Prop —— 角色决定 prompt 能重新描述什么
- 工作模式：Exploration / Continuation / Bridging / Repair（和 prompt 模式不同的两套分类法）
- Layer 1 brief ≠ Layer 2 production prompt —— Layer 1 永远不要贴进 prompt box
- 原生 **4K** 只在 `mode=std` 有；`mode=fast`（Seedance 2.0 Fast）封顶 480p/720p —— Cinema Studio 里模型也封顶 1080p
- 永远先 preflight：`python3 scripts/seedance_lint.py --preflight --model seedance_2_0 "<prompt>"` —— enum 来自 `../../specs/model-specs.json`（fast+1080p/4K 和 Kling 21:9 自动捕获）
- 480p 草稿验证 prompt 不验证成片 —— 无 seed；用 Hero Frame + 首尾帧锁视觉风格
- 中文 prompt：硬性 1800 字符上限；linter 强制 ZH antislop 词表
- 被 flag 的 prompt → 按 linter 规则改写 playbook，再做语气 pass
- 反复 flag → 完整 loop-breaker 流程 + 记录结果（`--confirmed` / `add-quality`）
08 higgsfield-soul Soul ID 角色一致性 
- Hard rule: every Soul ID prompt splits into Identity Block (static descriptors only) + Motion Block (temporal/camera only)
- Don't re-describe the face or core features — only describe what differs from the base character
- Reference image rules: front or 3/4 angle, even lighting, neutral-to-slight expression, no blur, solo subject
- Reference generators: Soul 2.0 (fashion-forward), Nano Banana Pro (max sharpness), Seedream 4.5 (style range)
- Character sheet angles: front face, 3/4, side profile, optional full body + optional embedded prop sheets
- Two-image floor per character: one clear face + one full body, on neutral grey — never a single image
- Prefer the single-prompt 3×2 six-panel sheet (one 16:9 generation) — identity locks better than multi-step assembly
- Outfit change without identity drift: split-panel sheet — ghost-mannequin outfit LEFT + "face matches input 100%" close-up RIGHT
- Crowds: a single-character reference makes a clone army — build a multi-character lineup and declare it a "VARIETY reference"
- Character Anchor Block = 10 per-shot attributes (identity, screen position, depth layer, frame occupancy, orientation, pose, gaze, contact points, state lock, expression)
- One Soul ID sheet PER character state — 5 transformation stages = 5 distinct sheets; the prompt names the stage
- Micro-expression presets: 9 core + 10 extended
- Cinema Studio: identity goes in the @ Element definition, motion goes in the prompt field
- Soul Cast is Business/Team plans only; 8 parameter categories incl. 12 Archetypes, Budget $10M–$500M, Era 1900s–2020s
- Soul Cast specs: up to 4K (Character/Location modes) / 2K (General); batch 1 or 10; 0.125 credits per image
- Use 2–3 reference shots (frontal, 3/4, side); if features drift, use the character sheet as @Image1
- Soul Cinema is the default CS 3.0/3.5 image-mode model — single-step, ~0.125 credits/image
- Studio-feeling output is an intermediate, not a final — re-pass through Soul Cinema with grade, directional lighting, lens character
- Skip Soul ID for single shots or when you want maximum creative variation
- Plasticky face in wide shots: crop the face from a closer-shot panel and replace it in post
- 硬性规则：每个 Soul ID prompt 拆成 Identity Block（只写静态特征）+ Motion Block（只写时序/镜头）
- 不要重复描述脸或核心特征 —— 只写相对基础角色的差异
- 参考图规则：正面或 3/4 角度、光线均匀、表情中性到略微笑、不模糊、单一主体
- 参考图生成器：Soul 2.0（时尚感强）、Nano Banana Pro（最高清晰度）、Seedream 4.5（风格范围广）
- 角色表角度：正面脸、3/4、侧脸，可选全身 + 可选嵌入道具表
- 每个角色至少两张图：一张清晰的脸 + 一张全身，中性灰底 —— 绝对不要只放一张
- 推荐单 prompt 3×2 六宫格表（一次 16:9 出图）—— 角色锁定比多步拼接更稳
- 换装不丢身份：分屏表 —— 左 ghost-mannequin 服装 + 右"face matches input 100%"特写
- 群戏：单角色参考图会变成克隆军团 —— 搭多角色 lineup 并标注为 "VARIETY reference"
- Character Anchor Block = 每个镜头的 10 个属性（身份、屏幕位置、深度层、画幅占比、朝向、姿势、视线、接触点、状态锁、表情）
- 一个 Soul ID sheet 对应一个角色状态 —— 5 个变身阶段 = 5 张不同 sheet；prompt 写明是哪个阶段
- 微表情预设：9 个核心 + 10 个扩展
- Cinema Studio：身份写进 @ Element 定义里，动作写进 prompt 字段
- Soul Cast 只在 Business/Team 计划有；8 个参数类别含 12 个 Archetype、Budget $10M–$500M、Era 1900s–2020s
- Soul Cast 规格：最高 4K（Character/Location 模式）/ 2K（General）；批量 1 或 10；0.125 credits/张
- 用 2–3 张参考图（正面、3/4、侧面）；如果特征漂移，用 character sheet 作 @Image1
- Soul Cinema 是 CS 3.0/3.5 默认 image-mode 模型 —— 单步，~0.125 credits/张
- "Studio 感"输出是中间态不是终片 —— 用 Soul Cinema 二次过色、定向光、镜头语态
- 单镜头或想要最大化创意变化时跳过 Soul ID
- 宽幅画面里脸部塑料感：从近景面板裁脸再后期贴回
